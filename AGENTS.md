# Repository instructions for coding agents

[`CLAUDE.md`](CLAUDE.md) is the repository-wide source of truth for coding-agent guidance. Its rules apply to Codex, OpenClaw, Claude Code, and any other agent working in this repository.

Before planning, editing, or reviewing changes:

1. Read `CLAUDE.md` in full and follow it as mandatory repository guidance.
2. Read the relevant files under `.cursor/rules/` when `CLAUDE.md` points to them or when the work touches the components they govern.
3. Preserve the development and pull-request process documented in `CLAUDE.md`, including the rules for keeping Shopify-owned upstream files pristine.

Shared guidance belongs in `CLAUDE.md`; do not duplicate it here, because duplicated rules can drift.
